# TMCOMTECH — Website Build 003 Preview

A mobile-first, static multi-page development preview for TMCOMTECH. **The site is not selling services, taking orders, or accepting customer files.**

## Pages

- `index.html` — home and development approach
- `about.html` — mission and commitments
- `hosting.html` — planned website hosting work
- `storage.html` — storage research direction
- `infrastructure.html` — engineering and operations
- `phoenix.html` — Project Phoenix public-service commitment
- `contact.html` — current contact status (no live inbox)

The website uses local assets only: `assets/style.css`, `assets/app.js`, and `assets/favicon.svg`. No frameworks, analytics, remote fonts, or third-party scripts.

## What's new in Build 003

- Navigation switches to a touch-friendly menu at tablet widths and closes on Escape, outside tap, link selection, or screen resize.
- Clear breadcrumbs and matching active-page links on inner pages.
- Improved mobile spacing, focus indicators, card interaction, and reduced-motion accessibility.
- More useful next-step links and a consistent footer navigation on all pages.
- Branded vector favicon. No change to the development-only status or Project Phoenix's free, ad-free identity.

## Review in Acode

1. Open the repository's `build-003-polish` branch, **not** `main`.
2. Preview `index.html`, open the mobile menu, and test every page link.
3. Review both portrait and landscape, plus the project and contact pages.
4. Approve before merging into `main` or deploying via Cloudflare Pages.

## Release safety

Project Phoenix is a distinct, permanently free, advertisement-free public-service project. TMCOMTECH is the proposed technology venture behind it, not a replacement. Build 003 remains a preview; no customer accounts, commercial services, or payment flows are available.
