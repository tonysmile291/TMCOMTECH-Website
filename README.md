# TMCOMTECH — Website Preview 002

A mobile-friendly, static multi-page website for TMCOMTECH. This is a **development preview**, not a live commercial service.

## Open in Acode

1. Extract the ZIP.
2. Open the `TMCOMTECH-Website` folder in Acode.
3. Preview `index.html`.
4. Test the navigation to `about.html`, `hosting.html`, `storage.html`, `infrastructure.html`, `phoenix.html`, and `contact.html`.

The design is self-contained: no external frameworks or network calls. All CSS and JavaScript are in `assets/`.

## Release safety

No forms collect user data, no services are sold, and no domain or company registration is implied. Project Phoenix is a separate, free, ad-free project.

## GitHub

This ZIP is for local review in Acode. No GitHub commits or pushes were made for Preview 002. After review, use a development branch before merging into main.
